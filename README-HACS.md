# Barcode-Scanner v3 mit Home-Assistant-Integration

Die vollständige Anleitung – Hardware, GM60-Einrichtung, ESPHome-Firmware v3.0 und Zusammenspiel mit Home Assistant – steht in der **[README.md](README.md)**.

Produktsuche, selbstlernende Datenbank, Seitenleisten-Panel, Push-Nachrichten mit Direkt-Antwort und die Einkaufsliste übernimmt die Integration **[SHYS Barcode Scanner](https://github.com/kallejoken/shys-barcode-scanner)** (installierbar über den Home Assistant Marketplace).
